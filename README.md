# JIKSONG

A direct-freight marketplace prototype connecting city households with regional family farms.

## Publish on GitHub Pages

1. Create a new repository on GitHub and upload everything in this folder (`index.html`, the `images` folder, `.nojekyll`, and this README).
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, then save.
4. After a minute or two your site is live at `https://<your-username>.github.io/<repository-name>/`.

## Notes

- Everything runs in the browser. Accounts, carts, orders and farmer listings are saved in each visitor's own browser storage, so different visitors don't share data.
- To reset the demo, clear the site's data in your browser.
